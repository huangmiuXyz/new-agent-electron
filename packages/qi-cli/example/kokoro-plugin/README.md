# Kokoro 本地语音合成插件

这个插件为 Agent-Qi 扩展 Kokoro 本地 TTS 能力，适合希望离线完成中英文语音合成的场景。

## 扩展了什么功能

- 接入 Kokoro 开源语音模型，实现本地文本转语音
- 支持中英文语音合成与多音色选择
- 支持语速调整并输出高质量 WAV 音频
- 提供后端服务自动启动能力，调用前可自动检测并拉起 Python 服务
- 支持在应用里把 Kokoro 作为独立 TTS Provider 使用

## 系统要求

- Python 3.8 及以上
- 建议 4GB 以上可用内存
- 可选 CUDA 环境，用于提升推理速度

## 使用方式

1. 安装并启用插件。
2. 确认本机可运行 Python。
3. 在 Agent-Qi 中添加 `kokoro` 类型提供商。
4. 配置服务地址，并建议开启“自动启动后端服务”。
5. 在语音设置中选择 Kokoro 音色开始使用。

## 手动启动后端

```bash
cd server
./start.sh
```

Windows 可使用：

```bash
start.bat
```

首次启动会自动创建虚拟环境并安装依赖。

## 适用平台

- 桌面端

## 注意事项

- 插件依赖本地 Python 服务，移动端不支持
- 模型路径、监听地址、端口和运行设备可通过环境变量进一步定制

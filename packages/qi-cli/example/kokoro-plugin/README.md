# Kokoro 本地语音合成插件

该插件用于在 Agent-Qi 中接入 Kokoro 本地语音合成服务。

## 启用后会增加什么

- 一个自动出现的 `Kokoro TTS` 提供商
- 一个默认模型：`Kokoro v1.1 中文`
- 本地音色列表
- 可选的本地服务自动启动能力

## 默认配置

- 默认服务地址：`http://localhost:18889`
- 默认服务端口：`18889`
- 默认最大并发数：`3`
- 自动启动后端服务：默认开启

## 当前内置音色

当前内置音色包含英文和中文音色，默认列表包括：

- `af_maple`
- `af_sol`
- `bf_vale`
- `zf_001` 到 `zf_008`
- `zm_009` 到 `zm_016`

如果本地服务的 `/voices` 接口可用，插件会优先读取服务返回的音色列表；否则使用内置音色列表。

## 使用前准备

- 可运行的 Python 环境
- 足够的本地内存
- 如需提升速度，可准备 CUDA 环境

## 使用方式

1. 启用插件。
2. 打开自动出现的 `Kokoro TTS` 提供商配置。
3. 填写服务地址，并按需调整端口、并发数和自动启动选项。
4. 保存配置。
5. 在语音设置中选择 `Kokoro TTS`、模型和音色。

## 适用平台

- 桌面端

## 注意事项

- 该插件依赖本地 Python 服务，移动端不支持

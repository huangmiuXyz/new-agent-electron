# Kokoro 本地语音合成插件

这个插件把 Kokoro 本地语音合成能力接入 Agent-Qi，适合希望在本机完成中英文 TTS、减少云端依赖、兼顾隐私和成本的用户。

## 这个插件能做什么

- 在本地把文本转换成语音
- 支持中英文语音合成
- 提供多种音色选择
- 支持调整语速并输出 WAV 音频
- 在调用前自动检测并启动本地语音服务

## 适合谁

- 希望离线使用语音合成的用户
- 不想把文本内容发送到云端 TTS 服务的人
- 需要在本机快速测试不同音色和语速的人

## 使用前需要准备

- 可运行的 Python 环境
- 足够的本地内存
- 如果想更快生成语音，可以准备 CUDA 环境

首次启动时，插件会自动准备本地运行所需依赖。

## 怎么使用

1. 启用插件。
2. 确认本机可以运行 Python。
3. 在 Agent-Qi 中添加 `kokoro` 类型提供商。
4. 配置服务地址，并按需开启自动启动后端服务。
5. 在语音设置中选择 Kokoro 音色开始使用。

## 适用平台

- 桌面端

## 注意事项

- 这个插件依赖本地 Python 服务，移动端不支持
- 首次启动可能需要一点时间来准备环境

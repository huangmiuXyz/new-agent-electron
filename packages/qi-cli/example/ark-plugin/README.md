# 火山引擎方舟多模态插件

这个插件把火山引擎方舟接入 Agent-Qi，让你可以在应用里直接使用 Ark 的文本、图像和视频能力，而不需要切换到别的平台操作。

## 这个插件能做什么

- 在 Agent-Qi 中新增“火山引擎方舟”提供商
- 使用 Ark 系列模型进行对话
- 使用 Ark 的图像生成能力出图
- 使用 Ark 的视频生成能力完成多模态创作
- 统一走 Agent-Qi 现有的模型选择和调用流程

## 适合谁

- 已经在使用火山引擎方舟 API 的用户
- 希望把聊天、出图、视频生成统一放在 Agent-Qi 里操作的用户
- 需要在同一个应用里管理多个模型平台的用户

## 使用前需要准备

- 火山引擎方舟账号
- 可用的 API Key
- 如果你的接入地址不是默认地址，还需要准备对应的 Base URL

## 怎么使用

1. 启用插件。
2. 打开 Agent-Qi 的模型提供商设置。
3. 新增或编辑“火山引擎方舟”提供商。
4. 填写 API Key，必要时修改 Base URL。
5. 刷新模型后，就可以在聊天、图像或视频场景中选择 Ark 模型。

## 适用平台

- 桌面端
- 移动端

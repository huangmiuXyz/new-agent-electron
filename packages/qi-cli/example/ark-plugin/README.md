# 火山引擎方舟多模态插件

该插件用于在 Agent-Qi 中接入火山引擎方舟。

## 启用后会增加什么

- 一个自动写入设置的方舟提供商
- 文本、图像和视频能力
- 图像和视频生成时的附加选项

## 默认配置

- 默认接口地址：`https://ark.cn-beijing.volces.com/api/v3`
- 提供商名称：`Ark`

## 图像与视频附加选项

图像生成支持：

- 顺序生成模式
- 水印开关
- 提示词优化模式
- Web 搜索工具

视频生成支持：

- 首帧图片
- 尾帧图片
- 是否生成音频
- 固定镜头
- 服务档位选择

## 使用前准备

- 火山引擎方舟账号
- 可用的 API Key
- 如有需要，准备自定义 Base URL

## 使用方式

1. 启用插件。
2. 打开模型提供商设置。
3. 编辑自动写入的 `Ark` 提供商。
4. 填写 API Key，并按需修改接口地址。
5. 刷新模型后，在相关功能中选择 Ark 模型。

## 适用平台

- 桌面端
- 移动端

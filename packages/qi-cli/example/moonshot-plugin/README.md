# Moonshot Kimi 大模型插件

该插件用于将 Moonshot AI 的 Kimi 系列模型接入 Agent-Qi。

## 主要功能

- 注册 `moonshotai` 类型的模型提供商能力
- 接入 Kimi 系列对话模型
- 纳入 Agent-Qi 的统一聊天模型配置流程

## 使用前准备

- Moonshot 账号
- 可用的 API Key
- 如有需要，准备自定义访问地址

## 使用方式

1. 启用插件。
2. 在 Agent-Qi 的模型提供商设置中手动新增 `moonshotai` 类型提供商。
3. 填写 API Key 和访问地址。
4. 刷新模型后，在聊天场景中选择相应模型。

## 适用平台

- 桌面端
- 移动端

# Moonshot Kimi 大模型插件

这个插件为 Agent-Qi 扩展 Moonshot AI（Kimi）大语言模型接入能力，方便直接把 Kimi 系列模型挂到应用的统一模型体系里。

## 扩展了什么功能

- 注册 `moonshotai` 模型工厂
- 支持在 Agent-Qi 中接入 Kimi 系列对话模型
- 让 Moonshot 模型参与统一的聊天、默认模型和 Provider 配置流程

## 使用方式

1. 启用插件。
2. 新增 `moonshotai` 类型提供商。
3. 填写 Moonshot API Key 和相关访问地址。
4. 刷新模型后即可在聊天场景中使用。

## 适用平台

- 桌面端
- 移动端

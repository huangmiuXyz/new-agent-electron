# Vosk 离线语音识别插件

该插件用于将 Vosk 的本地离线语音识别能力接入 Agent-Qi。

## 主要功能

- 在本地完成语音转文字
- 支持多语言识别模型
- 支持下载、切换和管理本地模型文件
- 支持实时语音识别

## 使用前准备

- 首次下载模型时需要联网
- 本机需要有足够空间保存语音模型

模型下载完成后可离线使用。

## 使用方式

1. 启用插件。
2. 打开插件自动注册的 `Vosk` 语音识别提供商。
3. 下载并启用所需语言模型。
4. 将默认语音识别提供商切换为 `Vosk`。
5. 待模型就绪后开始语音输入。

## 适用平台

- 桌面端

## 注意事项

- 首次使用某个语言模型时需要先下载
- 这个插件依赖桌面端本地模型文件，移动端不支持

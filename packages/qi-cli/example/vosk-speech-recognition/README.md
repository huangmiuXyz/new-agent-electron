# Vosk 离线语音识别插件

这个插件为 Agent-Qi 扩展纯本地离线语音识别能力，适合重视隐私和低延迟语音输入的场景。

## 扩展了什么功能

- 使用 `vosk-browser` 在本地完成语音转文字
- 支持中文、英文、日语、韩语、法语、德语等多语言模型
- 支持模型下载、切换和就绪状态展示
- 支持边说边转的实时识别体验

## 使用方式

1. 启用插件并选择 Vosk 作为语音识别提供商。
2. 在插件设置中下载需要的语言模型。
3. 等待模型状态变为“Ready”后开始语音输入。

## 适用平台

- 桌面端

## 注意事项

- 首次使用某个模型时需要联网下载
- 模型下载完成后会缓存在本地，后续可离线使用

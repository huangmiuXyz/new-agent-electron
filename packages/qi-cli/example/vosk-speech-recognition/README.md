# Vosk 离线语音识别插件

为应用提供完全隐私、零延迟的本地语音识别能力。

## 主要功能

- **100% 本地化**：所有语音处理均在浏览器内完成，无需上传音频到云端。
- **多语言支持**：支持中文（精简/完整）、英文、法语、德语、日语、韩语等 10+ 种语言模型。
- **实时识别**：极低的识别延迟，支持边说边转。
- **模型管理**：支持在线下载和动态切换不同的语言模型。

## 使用说明

1. 启用插件后，在应用设置中选择 Vosk 作为语音识别提供商。
2. 在 Vosk 设置界面选择并下载您需要的语言模型（如 `vosk-model-small-cn`）。
3. 待模型加载完成后（状态显示为“Ready”），即可开始离线语音输入。

## 注意事项

- 首次加载特定模型需要从网络下载，下载完成后将存储在浏览器缓存中，后续使用无需联网。

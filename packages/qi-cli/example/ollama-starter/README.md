# Ollama 自动启动器

这是一个功能增强型插件，专门为使用本地 Ollama 服务的用户设计。

## 主要功能

- **配置增强**：在 Ollama 提供商的设置界面增加“自动启动”开关。
- **智能检测**：在每次发起 AI 请求前，自动检查 Ollama 服务是否在线。
- **后台唤起**：如果服务未运行且开启了自动启动，插件会尝试在后台唤起 Ollama（支持 macOS、Windows 和 Linux）。
- **状态通知**：实时反馈 Ollama 的启动进度和结果。

## 使用方法

1. 安装并启用插件。
2. 进入“设置” -> “模型提供商” -> 选择或添加一个 Ollama 提供商。
3. 您会看到新增的“自动启动”复选框，勾选它。
4. 下次使用该提供商的模型时，插件将自动管理服务的启动。

# Ollama 自动启动器

这个插件不会新增一个新的模型 Provider，而是为已有的 Ollama 提供商扩展“自动启动”能力。

## 扩展了什么功能

- 在 Ollama 提供商设置页增加“自动启动”开关
- 在模型调用前自动探测 Ollama 服务是否在线
- 当服务未启动时，尝试在后台拉起本地 Ollama
- 用通知提示启动中、成功或超时失败等状态

## 使用方式

1. 安装并启用插件。
2. 打开已有的 Ollama 提供商配置。
3. 勾选“自动启动”。
4. 下次调用 Ollama 模型时，插件会在后台自动检查并启动服务。

## 适用平台

- 桌面端

## 注意事项

- 插件依赖本地进程启动能力，移动端不支持
- 如果系统环境里找不到 `ollama` 命令，自动启动会失败

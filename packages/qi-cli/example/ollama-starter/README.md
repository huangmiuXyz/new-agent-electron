# Ollama 自动启动器

该插件用于为现有 Ollama 提供商增加自动启动能力。

## 启用后会增加什么

- 在 Ollama 提供商配置中新增一个“自动启动”开关
- 在调用 Ollama 模型前自动检查服务状态
- 服务未启动时自动尝试拉起本地 Ollama

## 工作方式

- macOS：尝试通过 `open -a Ollama` 启动
- Windows：尝试通过系统命令启动
- 其他桌面系统：尝试执行 `ollama serve`

## 使用前准备

- 本机已安装 Ollama
- 系统环境中可以找到 `ollama` 命令
- Agent-Qi 中已存在可用的 Ollama 提供商

## 使用方式

1. 启用插件。
2. 打开现有的 Ollama 提供商配置。
3. 勾选“自动启动”。
4. 保存配置。
5. 在使用 Ollama 模型时，由插件自动检查并尝试启动服务。

## 适用平台

- 桌面端

## 注意事项

- 该插件不会新增新的模型提供商
- 该插件依赖本地进程启动能力，移动端不支持

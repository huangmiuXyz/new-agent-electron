# Ollama 自动启动器

这个插件不会新增新的模型提供商，它的作用是帮你把已有的 Ollama 服务管理得更省心。在调用 Ollama 模型前，插件会先检查服务状态，并在需要时尝试自动启动。

## 这个插件能做什么

- 给现有的 Ollama 提供商增加“自动启动”能力
- 在调用前自动检测 Ollama 是否在线
- 当服务未启动时尝试在后台拉起 Ollama
- 用通知提示启动中、成功或失败状态

## 适合谁

- 已经在使用 Ollama，但经常忘记先启动服务的人
- 希望本地模型调用流程更顺滑的桌面用户
- 想减少手动打开终端或命令行次数的人

## 使用前需要准备

- 本机已安装 Ollama
- 系统环境中可以找到 `ollama` 命令
- Agent-Qi 中已经存在可用的 Ollama 提供商

## 怎么使用

1. 启用插件。
2. 打开已有的 Ollama 提供商配置。
3. 勾选“自动启动”。
4. 下次调用 Ollama 模型时，插件会自动检查并尝试启动服务。

## 适用平台

- 桌面端

## 注意事项

- 这个插件依赖本地进程启动能力，移动端不支持
- 如果系统里找不到 `ollama` 命令，自动启动会失败

# Codex 代理服务插件

该插件用于在 Agent-Qi 中接入本机 Codex 登录状态和本地代理服务。

## 启用后会增加什么

- 一个自动出现的 `Codex 代理` 提供商
- 账号切换、额度查看和状态展示能力
- 本地桥接服务自动启动能力

## 当前内置模型

- `gpt-5.4`
- `gpt-5.3-codex`
- `gpt-5.3-codex-spark`
- `gpt-5.2-codex`
- `gpt-5.1-codex-max`
- `gpt-5.1-codex-mini`

默认模型为 `codex`，对应 `gpt-5.4`。

## 默认配置

- 本地服务地址：`127.0.0.1`
- 本地服务端口：`18123`
- 默认推理强度：`high`
- 认证来源：`~/.codex/auth.json`

## 使用前准备

- 本机已登录 Codex
- 本地存在 `~/.codex/auth.json`

## 使用方式

1. 启用插件。
2. 打开自动出现的 `Codex 代理` 提供商。
3. 确认当前账号信息可用。
4. 在聊天模型列表中选择 Codex 模型。
5. 首次调用时，由插件自动启动本地桥接服务。

## 适用平台

- 桌面端

## 注意事项

- 该插件依赖本地进程启动能力，移动端不支持

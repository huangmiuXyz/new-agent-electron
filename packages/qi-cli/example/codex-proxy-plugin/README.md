# Codex 代理服务插件

该插件用于将 Codex 以本地兼容提供商的形式接入 Agent-Qi。

## 主要功能

- 自动读取本机的 Codex 登录状态
- 自动注册 `Codex 代理` 提供商
- 在首次调用时启动本地桥接服务
- 提供模型调用与额度查询能力
- 在插件状态区域显示账号与用量信息

## 使用前准备

- 本机已登录 Codex
- 本地存在 `~/.codex/auth.json`

如果没有本机登录态，插件无法读取认证信息。

## 使用方式

1. 启用插件。
2. 打开插件自动注册的 `Codex 代理` 提供商。
3. 确认当前账号信息可用。
4. 在聊天或相关模型选择中使用 `Codex 代理`。
5. 首次调用时，插件会自动启动本地桥接服务。

## 适用平台

- 桌面端

## 注意事项

- 这个插件依赖本地进程启动能力，移动端不支持
- 如果本机没有 Codex 登录态，插件无法工作

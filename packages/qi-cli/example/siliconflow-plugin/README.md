# SiliconFlow 语音合成插件

该插件用于将 SiliconFlow 的语音合成能力接入 Agent-Qi。

## 主要功能

- 注册 `siliconflow` 类型的语音提供商能力
- 调用平台托管的 TTS 模型
- 获取平台可用音色并纳入 Agent-Qi 的语音配置流程

## 使用前准备

- SiliconFlow 账号
- 可用的 API Key

## 使用方式

1. 启用插件。
2. 在 Agent-Qi 的模型提供商设置中手动新增 `siliconflow` 类型提供商。
3. 填写 SiliconFlow API Key 并保存配置。
4. 在语音设置中选择相应模型和音色。

## 适用平台

- 桌面端
- 移动端

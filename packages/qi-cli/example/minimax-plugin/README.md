# MiniMax 语音合成插件

该插件用于将 MiniMax 的语音合成能力接入 Agent-Qi。

## 主要功能

- 注册 `minimax` 类型的语音提供商能力
- 调用 MiniMax 语音生成模型
- 获取平台提供的系统音色、克隆音色和生成音色

## 使用前准备

- MiniMax 账号
- 可用的 API Key

## 使用方式

1. 启用插件。
2. 在 Agent-Qi 的模型提供商设置中手动新增 `minimax` 类型提供商。
3. 填写 MiniMax API Key 并保存配置。
4. 在语音设置中选择相应模型和音色。

## 适用平台

- 桌面端
- 移动端

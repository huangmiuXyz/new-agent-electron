# MiniMax 语音合成插件

这个插件为 Agent-Qi 扩展 MiniMax（海螺 AI）TTS 能力，把云端语音合成和音色能力接入应用。

## 扩展了什么功能

- 注册 `minimax` 语音合成模型工厂
- 支持调用 MiniMax 语音生成模型
- 支持同步平台提供的系统音色、克隆音色和生成音色
- 可直接在 Agent-Qi 的语音设置中作为独立 Provider 使用

## 使用方式

1. 启用插件。
2. 添加 `minimax` 类型提供商。
3. 填写 MiniMax API Key。
4. 在语音设置里选择模型和音色开始生成。

## 适用平台

- 桌面端
- 移动端

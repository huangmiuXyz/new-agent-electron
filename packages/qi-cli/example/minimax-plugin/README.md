# MiniMax 语音合成插件

该插件用于在 Agent-Qi 中接入 MiniMax 语音合成服务。

## 启用后会增加什么

- 一个可手动添加的 MiniMax 语音提供商
- 可供选择的 MiniMax 语音模型
- 对应模型的系统音色、克隆音色和生成音色

## 当前可用模型

- `MiniMax Speech 2.6 HD`
- `MiniMax Speech 2.6 Turbo`
- `MiniMax Speech 02 HD`
- `MiniMax Speech 02 Turbo`
- `MiniMax Speech 01 HD`
- `MiniMax Speech 01 Turbo`
- `MiniMax Music 2.5+`
- `MiniMax Music 2.5`

说明：

- 以上 `Speech` 模型会附带音色列表
- 音色来源包括系统音色、克隆音色和生成音色
- `Music` 模型会显示为可选模型，但不附带音色列表

## 使用前准备

- MiniMax 账号
- 可用的 API Key

## 使用方式

1. 启用插件。
2. 在模型提供商设置中手动新增 MiniMax 提供商。
3. 填写 API Key 并保存配置。
4. 打开语音设置。
5. 选择 MiniMax 模型和音色后开始使用。

## 适用平台

- 桌面端
- 移动端

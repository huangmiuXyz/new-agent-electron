# MiniMax 语音合成插件

集成 MiniMax (海螺 AI) 的高品质语音合成 (TTS) 能力。

## 主要功能

- **语音合成 (TTS)**：支持 MiniMax 最新的语音生成模型（如 speech-2.6-hd）。
- **音色库支持**：自动同步 MiniMax 平台上的系统音色、声音克隆及生成音色。
- **注册表集成**：在系统中注册 `minimax` 模型工厂，专用于语音合成。

## 使用说明

1. 启用插件。
2. 在“提供商设置”中添加 `minimax` 类型的提供商。
3. 填入您的 MiniMax API Key。
4. 在应用的语音设置中即可选择 MiniMax 提供的丰富音色。

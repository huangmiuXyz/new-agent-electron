# ComfyUI 工作流出图插件

该插件用于在 Agent-Qi 中接入 ComfyUI API 工作流。

## 启用后会增加什么

- 一个自动出现的 `ComfyUI` 图像提供商
- 一个固定显示的模型：`ComfyUI Workflow`
- 基于工作流 JSON 的图片生成能力

## 默认配置

- 默认服务地址：`http://127.0.0.1:8000`
- 默认模型标识：`comfyui-workflow`
- 默认轮询间隔：`1500ms`
- 默认超时时间：`180 秒`

## 可配置字段

- 服务地址
- 工作流 JSON
- 提示词节点路径
- 负向提示词节点路径
- 随机种子节点路径
- 宽度节点路径
- 高度节点路径
- 批量数量节点路径
- 轮询间隔
- 超时时间

## 使用前准备

- 可访问的 ComfyUI 服务
- API 格式的工作流 JSON

## 使用方式

1. 启用插件。
2. 打开自动出现的 `ComfyUI` 提供商配置。
3. 填写服务地址和工作流 JSON。
4. 按需填写节点路径。
5. 在图像生成功能中选择 `ComfyUI Workflow`。

## 适用平台

- 桌面端
- 移动端

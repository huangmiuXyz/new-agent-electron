# Civitai 图像生成插件

该插件用于在 Agent-Qi 中接入 Civitai 的模型浏览与图片生成能力。

## 启用后会增加什么

- 一个自动出现的 `Civitai` 图像提供商
- 提供商页面中的模型检索与筛选界面
- 模型版本详情、示例图片和参数查看能力
- 将选定模型加入当前图像模型列表的能力

## 默认行为

- 默认图片模型会使用 Civitai AIR 标识
- 默认生成入口通过本地桥接服务转发请求
- 本地桥接服务默认端口：`18888`

## 可用筛选项

- 关键词
- 模型类型
- 排序方式
- 时间范围
- 标签
- 作者名
- 收藏、隐藏、仅主文件等布尔选项

## 使用前准备

- 可访问 Civitai 的网络环境
- Civitai API Key

## 使用方式

1. 启用插件。
2. 打开自动出现的 `Civitai` 提供商配置页面。
3. 填写 API Key。
4. 搜索或筛选模型，并将所需版本加入模型列表。
5. 在图像生成功能中选择已加入的 Civitai 模型。

## 适用平台

- 桌面端

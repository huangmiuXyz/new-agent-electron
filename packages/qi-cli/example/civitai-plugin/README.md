# Civitai 图像生成插件

该插件用于将 Civitai 的模型浏览与选模能力接入 Agent-Qi。

## 主要功能

- 在应用内浏览 Civitai 模型
- 按关键词、类型、排序方式等条件筛选模型
- 查看模型版本、示例图片和参数信息
- 将选定模型加入 Agent-Qi 的图像生成流程

## 使用前准备

- 可访问 Civitai 的网络环境
- Civitai API Key

API Key 不是必填项，但配置后通常可获得更完整的访问能力。

## 使用方式

1. 启用插件。
2. 打开插件自动注册的 `Civitai` 提供商配置页面。
3. 填写 API Key，并在同一页面浏览或搜索模型。
4. 在模型详情中选择所需版本并加入当前模型列表。
5. 在图像生成功能中选择已加入的 Civitai 模型。

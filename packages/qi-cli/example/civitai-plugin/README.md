# Civitai 图像生成插件

集成 Civitai 平台，为应用提供强大的模型浏览和图像生成能力。

## 主要功能

- **模型库浏览**：直接在应用内浏览 Civitai 上的热门模型。
- **高级搜索**：支持按关键词、类型、排序方式、周期等维度筛选模型。
- **一键使用**：发现喜欢的模型版本后，可直接将其添加为应用内的图像生成模型。
- **图片详情查看**：支持查看 Civitai 上的精选图片及其生成参数。

## 配置项

- **API Key**：访问 Civitai API 所需的密钥（可选，但建议配置以获得更好的访问体验）。

## 使用说明

1. 在插件设置中配置 Civitai API Key。
2. 打开插件详情页，浏览或搜索您感兴趣的模型。
3. 点击模型进入详情，选择合适的版本并添加到“我的模型”。
4. 在图像生成功能中选择已添加的 Civitai 模型即可开始创作。

# 智能密钥填充器

这是一个旨在简化配置流程的工具类插件。

## 主要功能

- **内置工具注册**：注册 `smartApiKeyFiller` 工具，可被系统或其他插件调用。
- **批量操作**：支持一次性为多个提供商（如 OpenAI, Anthropic, SiliconFlow 等）填充 API Key。
- **自动保存**：填充完成后自动更新系统设置，无需手动逐个保存。
- **结果报告**：生成详细的操作报告，告知哪些提供商填充成功，哪些失败。

## 使用场景

- **初次安装**：当您有多个平台的 Key 需要配置时。
- **批量更新**：当您更换了一批 API 密钥时。
- **AI 辅助配置**：在支持 Agent 的场景下，让 AI 协助您完成繁琐的 Key 填充工作。

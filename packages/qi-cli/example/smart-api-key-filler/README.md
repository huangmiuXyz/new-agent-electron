# 智能密钥填充器

这个插件是一个配置效率工具，用来帮你批量填写多个模型提供商的 API Key，减少逐个打开设置、复制粘贴和保存的重复操作。

## 这个插件能做什么

- 一次性为多个提供商批量写入 API Key
- 支持由系统或 Agent 调用完成自动填充
- 写入后直接更新系统设置
- 返回详细结果，方便确认哪些平台写入成功

## 适合谁

- 第一次配置多个模型平台的用户
- 需要批量轮换 API Key 的用户
- 想让 Agent 帮忙完成初始化配置的人

## 典型使用场景

- 新装应用后快速完成提供商初始化
- 同时更新 OpenAI、Moonshot、SiliconFlow 等多个平台密钥
- 在团队演示或测试环境中快速重置账号配置

## 适用平台

- 桌面端
- 移动端

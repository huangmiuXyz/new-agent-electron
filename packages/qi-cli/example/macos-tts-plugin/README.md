# macOS 原生语音合成插件

这个插件把 macOS 系统自带的 `say` 语音能力接入 Agent-Qi，适合想要零配置、本地离线、开箱即用语音合成体验的用户。

## 这个插件能做什么

- 直接调用 macOS 自带语音合成能力
- 自动读取系统已安装音色
- 无需 API Key、无需联网即可生成语音
- 输出标准音频文件，方便播放或保存

## 适合谁

- 使用 macOS 的桌面用户
- 想快速体验本地 TTS、不想额外注册云服务的人
- 更关注稳定和低门槛，而不是高级克隆音色能力的人

## 使用前需要准备

- 一台 macOS 设备
- 系统已安装的语音包

## 怎么使用

1. 启用插件。
2. 在模型提供商或语音设置中选择 `macos-tts`。
3. 选择系统音色后，直接开始语音合成。

## 适用平台

- 桌面端

## 注意事项

- 仅支持 macOS
- 可用音色数量取决于当前系统已安装的语音包

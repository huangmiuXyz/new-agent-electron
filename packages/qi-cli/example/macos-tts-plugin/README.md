# macOS 原生语音合成插件

这个插件为 Agent-Qi 扩展 macOS 系统自带 `say` 命令的语音合成能力，适合需要零配置、本地离线 TTS 的场景。

## 扩展了什么功能

- 接入 macOS 原生命令 `say` 作为 TTS Provider
- 自动读取系统已安装音色并展示到应用内
- 无需 API Key、无需联网即可生成语音
- 输出标准 WAV 音频，便于后续播放或保存

## 使用方式

1. 在 macOS 上安装并启用插件。
2. 在“模型提供商”或语音设置中选择 `macos-tts`。
3. 选择系统音色后即可直接进行语音合成。

## 适用平台

- 桌面端

## 注意事项

- 仅支持 macOS
- 可用音色数量取决于当前系统已安装的语音包

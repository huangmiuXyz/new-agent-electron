# MacOS 原生语音合成插件 (say)

集成 MacOS 系统自带的 `say` 命令，提供原生语音合成能力。

## 主要功能

- **原生 TTS**：使用 MacOS 自带的 `say` 命令进行语音合成。
- **无需联网**：完全本地运行，不消耗流量。
- **系统音色**：自动列出系统中安装的所有 MacOS 语音。
- **高质量输出**：生成 44.1kHz 16-bit PCM WAV 音频。

## 使用说明

1. 启用插件。
2. 在“提供商设置”中添加 `macos-tts` 类型的提供商。
3. 无需配置 API Key 或 Base URL。
4. 在应用的语音设置中选择 MacOS 原生音色。

## 注意事项

- 仅支持 macOS 系统。
- 语音列表取决于系统中已安装的语音包。

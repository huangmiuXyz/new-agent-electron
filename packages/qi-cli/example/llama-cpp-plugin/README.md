# llama.cpp 本地模型服务插件

该插件用于在 Agent-Qi 中接入本地 llama.cpp 服务。

## 启用后会增加什么

- 一个自动出现的 `llama.cpp Local` 提供商
- 本地模型扫描与加载界面
- 服务运行状态显示
- 本地 `llama-server` 的启动、切换和停止能力

## 默认配置

- 默认服务地址：`127.0.0.1`
- 默认端口：`8080`
- 默认上下文长度：`4096`
- 默认空闲自动停止时间：`10 分钟`

## 可管理内容

- `llama-server` 可执行文件路径
- 模型根目录
- 当前已加载模型
- 多模态模型对应的 `mmproj` 文件
- 额外启动参数

## 使用前准备

- 可用的 `llama-server`
- 本地 GGUF 模型文件
- 如使用多模态模型，准备对应的 `mmproj` 文件

## 使用方式

1. 启用插件。
2. 打开自动出现的 `llama.cpp Local` 提供商配置。
3. 配置 `llama-server` 路径和模型根目录。
4. 在模型加载入口中选择并加载本地模型。
5. 加载完成后，在聊天或向量化功能中选择对应模型。

## 适用平台

- 桌面端

## 注意事项

- 该插件依赖本地文件系统和 `llama-server`，移动端不支持

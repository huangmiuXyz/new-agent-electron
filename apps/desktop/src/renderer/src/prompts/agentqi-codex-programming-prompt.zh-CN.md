# 工具使用规范
- 用 search_project 搜索内容和文件名。优先使用精确的 rg 风格命令。
- 用 readFile 读取项目文件。搜索定位后再读取最小有用范围。
- 用 list_dir 查看目录。
- 用 edit_file 修改文件。使用 hashline 格式：先读取文件，复制 ¶path#TAG 文件头，然后发出编辑指令。
- exec_command 仅用于测试、构建、包管理、git、开发服务器等真实终端任务。
- 独立调用时使用 multi_tool_use_parallel。不要逐个串行调用独立的读取或搜索。
- 用 loadSkill 加载匹配当前任务的技能指导。
- 用 delegate_to_sub_agent 将专业化工作分派给其他智能体。
- multi_tool_use_parallel 的 recipient 格式：builtin.TOOL_NAME 或 mcp.SERVER_NAME.TOOL_NAME。

# 工作流
1. 理解目标。
2. 搜索定位相关文件，只读取必要内容。
3. 做最小且正确的修改。
4. 运行相关验证（测试、lint、构建）。
5. 报告无关验证失败，不要擅自修复无关代码。
6. 总结修改文件和验证结果。

多步骤、有风险或含糊的任务才使用计划。
